# 🎙️ Алиса x Google Gemini (Режим «Свой кент»)

Этот проект превращает вашу Яндекс.Станцию в умного, саркастичного и живого собеседника («друга-кента») на базе **Google Gemini 2.0 Flash**.

Работает **24/7 в облаке Vercel (бесплатно)**. Компьютер держать включённым **не нужно**. Никаких VPN на Станцию ставить не требуется — сервер Vercel находится в Европе и общается с Gemini напрямую.

---

## 📋 Пошаговая инструкция по настройке за 5 минут:

### Шаг 1. Получить бесплатный ключ Gemini API
1. Зайдите на сайт [Google AI Studio](https://aistudio.google.com/) (через ваш VPN SotaConnect).
2. Нажмите синюю кнопку **«Get API key»** → **«Create API key»**.
3. Скопируйте полученный ключ (начинается на `AIzaSy...`).

---

### Шаг 2. Развернуть проект на Vercel
Так как вы уже пользовались Vercel:
1. Зайдите на [github.com](https://github.com/) и создайте новый репозиторий (например, `alice-gemini-bot`).
2. Загрузите туда файлы из этой папки (`api/index.js`, `package.json`, `vercel.json`).
3. Зайдите на [vercel.com](https://vercel.com/) → нажмите **«Add New...»** → **«Project»** → импортируйте ваш репозиторий `alice-gemini-bot`.
4. В разделе **«Environment Variables»** добавьте переменную:
   * **Key:** `GEMINI_API_KEY`
   * **Value:** *(вставьте ваш ключ из Шага 1)*
5. Нажмите кнопку **«Deploy»**.
6. Через 20 секунд Vercel выдаст вам ссылку на проект, например:
   `https://alice-gemini-bot.vercel.app`

*(Проверить, что сервер работает: откройте эту ссылку в браузере — должно вывести `{"status":"online","service":"Alice Gemini Bro Bot"}`).*

---

### Шаг 3. Подключить к Яндекс.Станции (Яндекс.Диалоги)
1. Откройте в браузере консоль разработчика: [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer).
2. Войдите под тем же Яндекс-аккаунтом, к которому привязана ваша Станция.
3. Нажмите **«Создать диалог»** → выберите **«Навык в Алисе»**.
4. Заполните настройки:
   * **Название навыка:** например, `Мой Джемини` или `Джемини` (Яндекс требует понятные кириллические слова).
   * **Активационное имя:** совпадает с названием.
   * **Backend:** выберите **Webhook URL** и вставьте вашу ссылку из Vercel:
     `https://alice-gemini-bot.vercel.app`
   * **Голос:** выберите любой голос (например, стандартный голос Алисы или Шитов).
   * **Хранилище данных:** оставьте по умолчанию.
5. Нажмите внизу **«Сохранить»**.
6. Перейдите во вкладку **«Тестирование»** вверху страницы и напишите боту: *«Привет»*. Он должен ответить в стиле кента: *«Здорово, придурок! Чего звал?»*.

---

### 🗣️ Как пользоваться на Станции:

Скажите своей колонке:
> **«Алиса, запусти навык Мой Джемини»** *(или то имя, которое вы указали)*

Она запустит режим Gemini и поздоровается с вами. Дальше вы можете просто разговаривать вслух — она будет отвечать вам дерзко, смешно и по-человечески, помня последние фразы разговора.

Когда захотите закончить диалог, скажите:
> **«Хватит»** или **«Пока»**.
